## K02 — Atlas round trip (live Postgres; the bundle is a real Atlas export)

`tests/fixtures/okf/atlas-sample.zip` — rendered by Atlas's own exporter (profile
`atlas-okf-export/4`) from Atlas's test snapshot; 12 members (11 bundle files + manifest).
Import → pack (format `atlas`, root `bundle`, 7 concept documents, 0 conformance problems, 0
dangling links, 0 manifest warnings) → export: **every member byte-identical** to the archive;
re-import writes no revision. Export of a workspace pack with a dangling link is refused
(`LINK_DANGLING`) and succeeds once fixed. Hostile archives (traversal, absolute path, symlink,
script, case duplicate, compression bomb) are refused (unit tests).

## K10 — paraphrase-retrieval benchmark (live models, CPU)

`scripts/benchmark_embeddings.py` over the platform pack (18 documents, 18 sections) and 36
hand-labelled paraphrase questions (`tests/fixtures/okf/paraphrase-benchmark.json`); vector leg
only, cosine, document-level. Models downloaded once from Hugging Face into a scratch
environment (torch 2.14 CPU, sentence-transformers, transformers 5.17), then run offline.

| Provider | dim | recall@1 | recall@3 | MRR | seconds (corpus + questions) |
|---|---|---|---|---|---|
| hashing (feature-hash-v1) | 256 | 0.778 | 0.917 | 0.858 | 0.01 |
| sentence-transformers/all-MiniLM-L6-v2 | 384 | 0.722 | 0.972 | 0.836 | 1.8–5.7 |
| sentence-transformers/multi-qa-MiniLM-L6-cos-v1 | 384 | 0.778 | 0.917 | 0.862 | 2.8 |
| sentence-transformers/all-mpnet-base-v2 | 768 | 0.806 | 1.000 | 0.898 | 18.4 |
| **BAAI/bge-small-en-v1.5** (new default) | 384 | **0.917** | **1.000** | **0.958** | 8.7 |

Honest reading: the default model improves on hashing (MRR 0.858 → 0.958); the popular
all-MiniLM-L6-v2 does **not** beat hashing at recall@1 on this set. The question set was written
before any model was run, but it is small (36), several questions share words with their target
documents (which favours hashing), and the default was chosen as the best of four on this same
set — a selection effect. A larger, held-out set is P4-K05's retrieval benchmark.

Manual live run of the index with bge-small (`analystos knowledge reembed` path): reembed moved
18 sections to `sentence_transformers:BAAI/bge-small-en-v1.5:384`, column retyped to 384-d, HNSW
rebuilt, drop + reindex identical, then reembed back to hashing (256-d). Unit test
`test_paraphrase_benchmark_runs_for_hashing_and_the_local_model_when_present` passes with the
model installed (MRR model > hashing) and skips the model leg cleanly without the extra.

The `embeddings` extra is **not** installed in the shared `.venv` (torch is ~200 MB+); the fast
and integration suites run on hashing.
