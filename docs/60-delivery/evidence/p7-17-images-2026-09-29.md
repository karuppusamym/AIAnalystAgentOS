# P7-17 evidence: non-editable wheel, image sizes and cold start (2026-09-29)

Host: Windows 11, Docker Desktop 28.5.2 (Linux engine), python:3.11-slim base. Nothing was pushed or restarted; the
images below carry the unique tags `p717-{api,full}:{before,after}` and the running compose images were not touched.

## 1. Non-editable wheel

* `hatch_build.py` (a hatchling build hook, `[tool.hatch.build.targets.wheel.hooks.custom]`) bundles `config/`,
  `migrations/`, `packs/`, `alembic.ini` and the `connector-*.md` certification evidence under `analystos/_data/`
  (111 files). Editable installs skip the hook: the checkout is the data root.
* `core/config.py` resolves `DATA_ROOT` (read-only data: the checkout, else `analystos/_data`) and `STATE_ROOT`
  (writable `var/`, exported contracts: the checkout, else the working directory, never site-packages). Every consumer
  of the old `REPO_ROOT` moved to one of the two: `capabilities/registry.py` (packs), `cli.py` (alembic, contracts),
  `connectors/{certification,csv_file,kinds}.py`, `decisions/backends.py`, `demo/seed.py`, `workflows/queues.py`,
  `Settings` paths (models, OIDC mapping, agents, artifacts, uploads, sandbox masked paths). `analystos export-contracts`
  gained `--out DIR`.
* Verified from a fresh venv in a scratch directory (no repo, no extras, `pip install analystos-0.1.0-py3-none-any.whl`,
  1.7 MB wheel, 55 packages, cwd an empty folder):
  * `analystos.__file__` is under the venv's `site-packages`; `SOURCE_CHECKOUT=False`, `DATA_ROOT=.../site-packages/analystos/_data`,
    `STATE_ROOT=<cwd>`.
  * `analystos --help` lists the commands; `analystos export-contracts --out out` writes 37 contract files.
  * `from analystos.api.app import app` builds the FastAPI app (33 routes).
  * `Settings.models_config`, `agents_dir`, `oidc_mapping_file`, `kinds.CATALOG_PATH`, `registry.PACKS_DIR`,
    `certification.EVIDENCE_DIR`, `seed.DEMO_FILE` all exist; `registry.load(agents_dir=...)` loads 127 capabilities with no problems;
    the bundled alembic script directory resolves to head `0045`; `workflows.queues.load_config()` reads 7 queues.
* Tests: `tests/unit/test_wheel_contents.py` (runs the hook, builds the real wheel with hatchling, checks every runtime path
  the code resolves, the playbooks, migrations, evidence, no `__pycache__`, no stray top-level `tests/docs/config/web`,
  and that the Dockerfile installs a wheel, not `-e`).

## 2. Images

`deploy/docker/Dockerfile` is now two stages: `pip wheel --no-deps` builds the wheel, the runtime stage installs it
with the extras (`EXTRAS`). Before = the Dockerfile at HEAD f1d6c36 (`pip install -e`, `PYTHONDONTWRITEBYTECODE=1`, so
every module recompiled in each process start); after = this change (byte-compiled at install, data inside the wheel).
`api` = `EXTRAS=reports` (Dockerfile default, the slim API image); `full` = `EXTRAS=standard` (worker image).

| image | disk (unpacked, `docker images`) | compressed content (`docker image inspect .Size`) |
|---|---|---|
| api before | 1.43 GB | 329.5 MB |
| api after  | 1.44 GB | 331.9 MB |
| full before | 1.69 GB | 383.1 MB |
| full after  | 1.70 GB | 385.5 MB |

Sizes are unchanged within 1% (+2.4 MB: bytecode and the bundled data copy). The slim API image is 0.26 GB smaller
than the full image; the size of the slim image is dominated by pandas/pyarrow/duckdb/matplotlib, not by this change.

### Cold start

Method: `docker run -d` (fresh container, no dependencies reachable: no Postgres/Redis) to the first HTTP 200 from
`/api/health`, polled every 50 ms, 5 runs per image interleaved before/after, host page cache warm. The health answer
includes the 2 s dependency deadline, so the floor is about 2 s.

| image | runs (ms) | median |
|---|---|---|
| api before | 5059, 4469, 4381, 4139, 4353 | 4381 |
| api after  | 4076, 4355, 3950, 4627, 4174 | 4174 (-5%) |
| full before | 4937, 4826, 4432, 5298, 4537 | 4826 |
| full after  | 4444, 4034, 3889, 4092, 4321 | 4092 (-15%) |

`docker run --rm IMG python -c "import analystos.api.app"` (container create + interpreter + full app import), 5 runs:
api before median 3770 ms (3684, 3770, 3749, 4031, 4641), api after 3508 ms (3424, 3463, 3508, 4044, 3863), -7%.
In the after image `pip show analystos` reports an installed (non-editable) package at site-packages and
`SOURCE_CHECKOUT=False`; before it was an editable project at `/app`.
