# P4-T02 evidence — deterministic-first by default (2026-09-25 18:30 UTC)

**Not live models.** Both runs use a counting *fake* transport (`tests/integration/test_token_default.py`,
`CountingTransport`): every chat call is answered `{}` (1,000 prompt + 100 completion tokens, $0.001) and
every decision call with no answers (205 tokens, $0.00002). Model output therefore never changes a finding;
what is measured is **how many calls the platform decides to make** under the default settings. Token and
cost numbers are the fake's accounting, not provider prices.

  objective "Find the drivers of SLA breaches in IT incidents", publication approved to the preview destination,
  run to `COMPLETED`.
- Settings: the platform defaults (no settings version stored; no preset applied), a model provider "available"
  (API key present), response cache in-process, workspace policy defaults.
- Before: the tree at `8217457` (HEAD before this change), extracted with `git archive` and run with the same test
  file (`pytest -o pythonpath=<extracted src>`). After: this branch.
- Test databases `analystos_test_w2a` / `analystos_test_dp_w2a`; the main `analystos` database was not touched.

### Confidence (not part of the unchanged check)

Per-finding confidence moved from 0.75/0.70 to 0.85/0.80. Cause: before, the fake independent-family review
answered `{}`, which the critic reads as "does not support" (−0.1); after, that review is off by policy and has no

## Reproduce

```bash
ANALYSTOS_TEST_DATABASE_URL=postgresql+psycopg://analystos:analystos@localhost:5432/analystos_test_<you> \
ANALYSTOS_TEST_DP_DB=analystos_test_dp_<you> ANALYSTOS_TOKEN_EVIDENCE_OUT=/tmp/after.json \
  .venv/bin/pytest -q -m integration tests/integration/test_token_default.py
```

The same test asserts ≥ 3 verified findings, ≤ 10 chat calls, and that the run's calls and tokens stay within the
committed cost-gate baseline (`tests/fixtures/cost_baseline/baseline.json`, P4-T10). Setting
`ANALYSTOS_COST_FIXTURE_RECORD=1` refreshes the `standard_run` cost-gate recording from this run.
